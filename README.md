# CRYSTAL DEFENDERS R2 한국어 패치

CRYSTAL DEFENDERS R2의 비공식 한국어화 프로젝트입니다.

## 대상

- 플랫폼: WiiWare
- 게임: CRYSTAL DEFENDERS R2 (일본어판)
- 언어: 일본어 → 한국어

## 패치 소개

게임 내 대사와 메뉴, 시스템 메시지 등을 한국어로 번역하고
폰트 및 이미지 리소스를 수정하여 한국어가 정상적으로 표시되도록 작업했습니다.

## 다운로드

최신 패치는 [Releases](../../releases)에서 받을 수 있습니다.

## xdelta 패치 적용 방법

1. 원본 게임 이미지의 MD5를 확인합니다.
2. MD5가 `725736cff46da378d406bc07d30e73a7`인지 확인합니다.
3. xdelta 패치 프로그램을 준비합니다.
4. 원본 게임 이미지와 `r2v1.xdelta`를 지정합니다.
5. 패치를 적용하여 한국어판 이미지를 생성합니다.

※ 반드시 원본 이미지의 해시를 확인한 후 패치해 주세요.

## 주의사항

본 패치는 비영리 팬 프로젝트입니다.
원본 게임 파일은 포함하지 않습니다.

정품 게임을 보유한 사용자가 개인적인 목적으로
이용하는 것을 전제로 배포합니다.
